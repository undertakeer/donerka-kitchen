# Миграции

`../schema.sql` — полная схема версии 1. Его прогоняют первым.

Каждое следующее изменение базы — отдельный файл здесь: `002_….sql`, `003_….sql` и т.д.
Каждый файл:
- прогоняется поверх уже существующей базы и ничего не удаляет;
- в конце поднимает `schema_version` в таблице `app_meta`;
- безопасен при повторном прогоне.

Приложение само проверяет версию базы и, если она отстала, пишет, какие файлы прогнать.
