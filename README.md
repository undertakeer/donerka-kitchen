# Кухня Donerka

Задачи кухни на сегодня: повар отмечает сделанное, управляющий ставит задачи и видит всё в реальном времени.

**Адрес приложения:** https://undertakeer.github.io/donerka-kitchen/

> **Если приложение однажды не открылось** — зайдите на supabase.com → ваш проект → нажмите **Restore** (бесплатный проект засыпает после недели простоя).

---

## Первый запуск (один раз)

### 1. База
1. supabase.com → ваш проект → слева **SQL Editor** → **New query**.
2. Откройте файл [`supabase/schema.sql`](supabase/schema.sql), скопируйте **весь** текст, вставьте, нажмите **Run**.
3. Внизу должно появиться «Success. No rows returned».

### 2. Запретить чужую регистрацию
**Authentication → Sign In / Providers → Email**: выключите **Allow new users to sign up** → Save.
(Даже если забыть — чужой аккаунт не получит доступа: доступ есть только у логинов из списка в базе.)

### 3. Завести два аккаунта
**Authentication → Users → Add user → Create new user**:

| Email (так и вписать) | Пароль | Галочка |
|---|---|---|
| `admin@donerka.local` | придумайте | **Auto Confirm User** — включить |
| `kuhnya@donerka.local` | придумайте | **Auto Confirm User** — включить |

В приложении вводится только логин: `admin` или `kuhnya`.

### 4. Войти
Откройте адрес приложения → логин `admin` → пароль. Внизу «Ещё → Сотрудники» — добавьте имена, кто работает на кухне.

### 5. Поставить на телефон
Айфон: Safari → «Поделиться» → «На экран „Домой“». Подробно — в приложении: «Ещё → Установить на телефон».

## Изменения базы в будущем
Каждое изменение — отдельный файл в `supabase/migrations/` (`002_…sql`, `003_…sql`). Его вставляют в SQL Editor и нажимают Run поверх существующей базы — ничего не удаляется. Если файл забыли прогнать, приложение само напишет, какой.

## Секреты
В репозитории лежат только адрес проекта и **publishable**-ключ — они и так видны в браузере. Секретный ключ (secret / service_role) **никогда** не кладётся в репозиторий; `npm run check:secrets` проверяет это перед каждой выкладкой.

## Для разработки

```bash
npm install
npm run dev          # локально, с настоящей базой
npm run check        # всё: линтер, модульные, прогон экранов в jsdom, сборка, секреты, визуальный прогон в Chrome
```

- `src/lib/` — даты (ташкентское время, день начинается в 04:00), расписания, количества, очередь отметок. Покрыто `tests/unit`.
- `src/data/store.js` — локальная копия + очередь изменений: экран = база + ещё не отправленное. Отказ базы → действие убирается, экран возвращается к правде.
- `src/data/fakeBackend.js` — база в памяти для проверок (`npm run build:demo`).
- `tests/visual/screenshots/` — скриншоты последнего визуального прогона.
